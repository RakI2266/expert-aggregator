# Премиальный слой (3D + «воздух»)

Затронуты только landing.html и experts.html.

Новые файлы:
- css/air.css  - весь «воздух», шрифты, цвета, отступы (одно место для обоих лендингов)
- js/hero3d.js - 3D-сцена первого экрана (настройки в блоке CONFIG вверху файла)
- js/how3d.js  - 3D-панель в блоке «Как это работает» (настройки в CONFIG)
- js/three.min.js - библиотека three.js (r149), локально
- js/reveal.js - плавное появление текста (заголовки из-под линии, абзацы мягким подъёмом; настройки в CONFIG)
- assets/fonts/ - шрифт Onest, локально (интернет не нужен)

Быстрые правки:
- отступы между блоками: css/air.css -> --space-section
- шрифт: css/air.css -> --font-body
- сила свечения 3D: hero3d.js / how3d.js -> CONFIG.glow
- сцена справа/слева: hero3d.js -> CONFIG.offsetX (минус = слева)

Файл landing-premium.html - старая копия без изменений (можно удалить).
